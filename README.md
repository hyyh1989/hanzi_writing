# 米字格练字本

给 5 岁小朋友的汉字**书写**练习。认字由洪恩识字和课本负责，本项目只管「写」。

针对的具体问题：**在纸上写字时，位置、大小、间架结构不稳。**

## 一、日常怎么用

```
课本/洪恩认字  →  【练习】跨单元挑字听写（测）  →  错字自动进描红默写（练）  →  打印字帖（纸上巩固）
```

三个页签：

### 学习
按课本顺序浏览**人教版一年级上册识字表 41 课 300 字**。点任意一个字进入：

**看笔顺 → 描红 ×3 → 默写 ×3**（格数可改成 5）

每课下面标出这一课的字里哪些属于本册**要求会写**的 100 字，其余只要求认识。
右上角可切到「按笔画难度」——内置 9 关，从横竖起步到包围结构，按**写字**难度递进。

### 字库
按主题浏览（数字、身体、家人、动物、颜色、动作……）。认字量大了之后横向串联用。

### 练习
**勾选要听写的字，可以跨单元一起选** —— 点单元名前面的方块整组勾选，也可以只点某几个字。
底部一直显示已选字数，两个出口：

- **开始听写** —— 顺序随机打乱
- **打印字帖** —— 按课本顺序

「只选要求会写的」一键勾出本册 100 个写字表字。

## 二、核心功能

**起笔点引导** —— 每一笔开始前，格子里标出红色起笔点（带笔序号）+ 方向箭头，
并用米字格方位词语音提示：「第一笔，从横中线的左边起笔」。
写字教学里起笔位置是一切的源头，第一笔偏了后面全在将错就错。

**只显示她自己的笔迹** —— 写完一笔不会被换成标准笔画。描红时浅色底字留在下面，
一眼看出差在哪。

**三项独立打分**
- **位置** —— 笔迹外框中心 vs 标准中心的偏移
- **大小** —— 两个外框的边长比
- **间架** —— 先把笔迹平移+缩放到标准位置，再算每一笔重心的残差
  （这样才能把「整体写小了」从「内部结构散了」里剥离出来）

反馈**只说一条**（最弱的那项），而且说的是**怎么改**不是「偏了」：
「第 3 笔要高一点、往左一点，这一笔应该从竖中线的上半段起笔」。语音念出来，她不用认字。
已经三星时不纠错，改成「再注意一点会更棒」。

**听写** —— 显示拼音，语音念「字 + 两个组词」（「地，大地的地，土地的地」——
一个词孩子常常还对不上号）。自由书写、不给任何提示、不判笔顺，这是考试不是练习。
写完批改：左右并排「她写的 / 标准字」，自动给出笔画数、整体偏向、大小的客观提示，
**默认全算对，你只把没写对的点出来**。结果页一键把错字送进描红默写。

**打印字帖** —— A4 米字格 35mm。每个字两行：上面**笔顺分解**（黑点标出每一笔从哪起笔），
下面**练习行**（1 格范字 + 2 格描红 + 2 格空白）。屏幕上的预览就是打印出来的样子。

**备份 / 恢复** —— 见下方「数据」。

**设置** —— 朗读读音、提示音效、判定宽松度、语音点评、起笔点提示、朗读声音与语速、版本号。

## 三、以后怎么更新

代码改完（通常是我改），你在 Mac 上跑一条命令：

```bash
~/MyProjects/hanzi_writing/build/deploy.sh
```

项目已经建好，**不会再问任何问题**，直接上传。跑完在 iPad 上打开
https://hanzi-writing.pages.dev → 设置 ⚙ → 看「版本」是不是刚才那个时间。

正常情况下不用手动刷新（配了 `no-cache`，每次打开都跟服务器核对）。
万一还是旧的，点设置里的**「检查更新」**。

### 如果 wrangler 提示没登录

```bash
npx wrangler login
```

浏览器打开后**尽快**点 Allow，**只点一次**，别刷新别按返回（授权凭证是一次性的，
重复提交会报 `The consent verifier has already been used`）。开着 VPN 先关掉。

实在不行用 API Token（不走浏览器回调）：
https://dash.cloudflare.com/profile/api-tokens → Create Token → 模板 "Edit Cloudflare Workers"
→ 复制后 `export CLOUDFLARE_API_TOKEN=你的token` 再部署。**token 别提交进 git、别发给任何人。**

### 改完想先看看再上线

我会把改动发布到上面那个 Claude 预览地址，你在那儿确认没问题，再跑 deploy。

## 四、改内容

### 改字表（换册、加字）

编辑 `build/textbook.py`（识字表 `TEXTBOOK` + 写字表 `XIEZI`），然后：

```bash
/usr/local/bin/python3 ~/MyProjects/hanzi_writing/build/make_chardata.py
```

如果 `build/cache/` 是空的（刚 clone），先跑一次下载全部笔顺数据（约 10 分钟）：

```bash
/usr/local/bin/python3 ~/MyProjects/hanzi_writing/build/fetch_all.py
```

### 改听写组词

编辑 `build/words_core.py`（`CORE_WORDS` 第一个词 + `CORE_WORDS2` 第二个词），然后：

```bash
/usr/local/bin/python3 ~/MyProjects/hanzi_writing/build/make_words.py
```

### 改图标

编辑 `build/make_icons.py`，然后跑它。

改完任何一项，都要再跑一次 `build/deploy.sh` 才会上线。

## 五、字库覆盖

**9574 个字**，等于 hanzi-writer-data 的全部内容。「魑魅魍魉」这类生僻字都有；
「龘」「犇」「燚」这种超生僻/异体字没有。

页面本身只内联 477 个常用字（约 1 MB，含教材全部 300 字），其余分成 128 片，
用到哪个字才下哪一片（每片约 240 KB，不到 1 秒），下过就缓存住。

教材数据的来源和校验方法写在 `build/textbook.py` 文件头。

## 六、数据与备份

**没有账号系统，也不需要。** 没有登录、没有服务器、没有任何网络请求
（除了第一次加载页面和按需取笔顺分片）。

所有数据只存在那台设备的浏览器里：

| 存的东西 | key |
|---|---|
| 每个字的最好成绩（星星） | `mzg.stars` |
| 练习页勾选的字 | `mzg.sel` |
| 设置（声音/语速/宽松度/起笔点/分组…） | `mzg.cfg` |

### ⚠️ 三种情况会丢

1. 清理 Safari 数据
2. 换设备
3. **换网址** —— 浏览器按网址隔离数据，`192.168.x.x:8080`、`hanzi-writing.pages.dev`、
   Claude 预览地址，在浏览器眼里是三台不同的设备

所以 app 里有 **设置 ⚙ → 备份 / 恢复**：

- **备份**：生成一段文字，「复制」粘到备忘录里存着
- **恢复**：把那段文字贴回去，星星、勾选、设置全回来

换网址搬家也走这条路。没备份过的话设置里会红字提醒「从未备份」。

启动时会向系统申请持久化存储降低被自动清理的概率，但那是「申请」不是保证，**该备份还是要备份**。

> iOS 的「添加到主屏幕」web app 有自己独立的存储空间，和 Safari 里打开的不共用。
> **固定从桌面图标进**，别一会儿桌面一会儿 Safari，否则星星看起来会「消失」。
