## 一、日常怎么用

### 首页 =「今天」

打开就是今天要做的事，从上到下：

- **小猫 + 本周打卡**：来过的日子是实心的青色圆点，没来的只是空着（不打叉，也不算「连续几天」）
- **今天的任务**：按「每周计划」自动出题，卡片上直接写着要练哪几个字，比如「写 3 个字：大 马 土」。
  点「开始」直接进练字页，写完最后一个会显示「回到今天」，任务自动打勾。
  当天的内容是固定的；卡片下方的小字「换一批」「今天跳过」给家长用。
  全部做完，小猫开心一次。**周日休息**
- **小游戏**：认字小游戏、听音选词（英文）、音符拼单词（音乐），各自一天 3 局，随时能玩，不需要先做任务
- **科目**：最下面四张卡片，进中文 / 数学 / 英文 / 音乐随便练

进了科目页或练字页，左上角是面包屑「🏠 首页 › 中文 › 练"天"」，点哪一格回哪一层。

### 每周计划（家长设）

设置 ⚙ → 每周计划 → 编辑。每天点选要做的任务。默认（钢琴课周日上，周一复习、周六热身）：

| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|---|---|---|---|---|---|---|
| 写谱号音符 + 中文写字 | 中文写字 + 拼单词 | 认音符 + 中文写字 | 中文写字 + 写数字 | 写谱号音符 + 拼单词 | 中文听写 + 认音符 | 休息 |

（改过计划的话默认值不会自动套上，想加新任务就在编辑页里点上。）

最下面可以加**线下任务**（比如「钢琴练 10 分钟」「和妈妈读一本绘本」），排进哪天，
那天首页就多一个勾选框，做完你来勾。

**每天出什么题**：

| 任务 | 数量 | 先挑什么 |
|---|---|---|
| 中文写字 | 3 个 | 要多练的字 → 学过的课里要求会写的（最近的课在前）→ 其余学过的字 |
| 英文拼单词 | 3 个 | 要多练的 → 两张词表都有的 → 只在例外词表上的 → 高频词；短的先练（a、I 不进任务） |
| 英文写字母 | 4 个 | 要多练的 → 容易写反的 b d p q s z j N S Z J → 其余 |
| 数学写数字 | 3 个 | 要多练的 → 2 3 5 7 9 → 其余 |
| 中文听写 | 最多 8 个 | 这一周练过的 + 要多练的 + 当前这一课 |
| 音乐认音符 | 一轮 10 个 | 高音谱号 Middle C → Treble C、低音谱号 Bass C → Middle C，低音谱号占几个在音乐页调 |
| 音乐写谱号和音符 | 2 项 | 一个谱号 + 一串音符，没练熟、越久没练的优先 |

同一组里没练到三颗星的优先，再按越久没练越靠前，所以每天自动轮换。
「学到第几课」在设置里，她往前学一课就往后调一格。

### 数学、英文

点数字或字母进**和汉字同一个练字页**：看笔顺 → 描红 → 默写。格子换成四线格（红线是基线），
字母用英式英语念（z 念「zed」），写法按她 2026-09-27 确认过的（单层 a/g、末尾带小尾巴等，见 ENGLISH.md）。
写反方向会被当场判错并示范正确笔顺。

**英文单词**（英文页最上面）：这学期学校发的两张词表，例外词 45 个 + 高频词 100 个，合计 113 个。
颜色照学校的 Monster Phonics 词表逐个字母抄的：同一种颜色是同一个音，空心字母不发音。
点一个词：**听 → 描红（一个字母一格）→ 默写**（词被盖住，听着自己拼）。
默写时写成别的字母会被判错，同一笔错 3 次才示范；看了示范的词自动进「要多练的单词」。
图只有 mum、dad、house 这类画得出来的 9 个词有，而且**写完/读对之后**才出现（学校要求不能看图猜词）。

### 音乐（提示全部英文，钢琴老师上课用英文）

- **认音符**：五线谱上出一个音（先画出谱号），在下面的琴键上点对应的键。琴键标着字母、Middle C 有标记；
  换谱号时键盘整条左右滑，两个谱号的 Middle C 是同一个键。答对弹出音高、说「Yes! That's E.」
- **写谱号**：高音谱号、低音谱号，起笔先点圆，从 G 线 / F 线开始。描一遍、写两遍
- **写音符**：和练习册一样写一串二分音符——高音谱号 Middle C D E F G，低音谱号 F G A B Middle C。
  写到后面整串往左滑；Middle C 要连加线一起写；符干朝向跟着位置走
- 开头不讲解，写错了才示范并说一句英文；做法和依据见 MUSIC.md
- **音符拼单词**（首页小游戏）：五线谱上一串音符，在琴键上按顺序点出来拼成单词（A–G 以外的字母直接印出来，
  比如 had = h + A D）。一局 6 个词看用多久，只看字母不看八度，拼出来才出图

**听音选词**（首页小游戏）：听一个词，从 4 个词里点对的。干扰项专挑容易混的（was/saw、no/on、of/off……），
规矩和认字小游戏一样：看用多久、答错不前进。

## 二、中文

**练习页**（2026-10-06）：上面可以切「教材 / 洪恩识字」两张字表。洪恩识字的顺序要自己录：点「编辑洪恩字表」，
按洪恩里学的顺序把字打进去或粘贴进去，保存后每 10 个字自动分一个单元。
勾好字后，最下面有三个按钮：**打印字帖**、**开始练字**（直接描红、默写）、**开始听写**。

### 学习
按课本顺序浏览**人教版（2024 新版）一年级上册识字表 38 课 280 字**。点任意一个字进入：

**看笔顺 → 描红 ×3 → 默写 ×3**（格数可改成 5）

每课下面标出这一课的字里哪些属于本册**要求会写**的 100 字，其余只要求认识。
右上角可切到「按笔画难度」——内置 9 关，从横竖起步到包围结构，按**写字**难度递进。

### 字库
按主题浏览（数字、身体、家人、动物、颜色、动作……）。认字量大了之后横向串联用。

### 练习
**顶上是「要多练的字」** —— 任何一次听写判成「没写对」的字都会自动攒进来，**不会自己消失**。
角标是错过几次，错得多的排前面。可以整组勾上跟新课一起考；
点「整理」进入删除模式，把已经掌握的点掉。

下面是课本 41 课。**勾选要听写的字，可以跨单元一起选** —— 点单元名前面的方块整组勾选，也可以只点某几个字。
底部一直显示已选字数，两个出口：

- **开始听写** —— 顺序随机打乱
- **打印字帖** —— 按课本顺序

两个快捷键：「只选要求会写的」勾出本册 100 个写字表字，「只选要多练的字」勾出所有错过的字。

## 二（续）、核心功能

**起笔点引导** —— 每一笔开始前，格子里标出红色起笔点（带笔序号）+ 方向箭头，
并用米字格方位词语音提示：「第一笔，从横中线的左边起笔」。
写字教学里起笔位置是一切的源头，第一笔偏了后面全在将错就错。

**只显示她自己的笔迹** —— 写完一笔不会被换成标准笔画。描红时浅色底字留在下面，
一眼看出差在哪。

**三项独立打分**
- **位置** —— 笔迹外框中心 vs 标准中心的偏移
- **大小** —— 两个外框的边长比
- **间架** —— 先把笔迹平移+缩放到标准位置，再算每一笔重心的残差
  （这样才能把「整体写小了」从「内部结构散了」里剥离出来）

反馈**只说一条**（最弱的那项），而且说的是**怎么改**不是「偏了」：
「第 3 笔要高一点、往左一点，这一笔应该从竖中线的上半段起笔」。

**语音刻意说得少**：每格只说一句鼓励（「写得真好！」「不错，继续。」），
具体怎么改**只在整行写完时说一次**，写得好就不挑毛病。详细建议一直显示在屏幕上给你看，
想听点评分卡上的 🔊。原则是：语音给孩子，屏幕给家长。

**「↶ 这笔重写」** —— 写完一笔不满意，一键退回重写这一笔，前面的笔画保留。

**听写** —— 显示拼音，语音念「字 + 两个组词」（「地，大地的地，土地的地」——
一个词孩子常常还对不上号）。自由书写、不给任何提示、不判笔顺，这是考试不是练习。
写完批改：左右并排「她写的 / 标准字」，自动给出笔画数、整体偏向、大小的客观提示，
**默认全算对，你只把没写对的点出来**。结果页一键把错字送进描红默写。

**打印字帖** —— A4 米字格 35mm。每个字两行：上面**笔顺分解**（黑点标出每一笔从哪起笔），
下面**练习行**（1 格范字 + 2 格描红 + 2 格空白）。屏幕上的预览就是打印出来的样子。

**备份 / 恢复** —— 见下方「数据」。

**设置** —— 朗读读音、提示音效、判定宽松度、语音点评、起笔点提示、朗读声音与语速、版本号。

代码改完（通常是我改），你在 Mac 上跑一条命令：

```bash
~/MyProjects/hanzi_writing/build/deploy.sh
```

项目已经建好，**不会再问任何问题**，直接上传。跑完在 iPad 上打开

万一还是旧的，点设置里的**「检查更新」**。

### 如果 wrangler 提示没登录

```bash
npx wrangler login
```

浏览器打开后**尽快**点 Allow，**只点一次**，别刷新别按返回（授权凭证是一次性的，
重复提交会报 `The consent verifier has already been used`）。开着 VPN 先关掉。

https://dash.cloudflare.com/profile/api-tokens → Create Token → 模板 "Edit Cloudflare Workers"
→ 复制后 `export CLOUDFLARE_API_TOKEN=你的token` 再部署。**token 别提交进 git、别发给任何人。**

### 改完想先看看再上线（预览站）

大改动我会在单独的开发分支上做，你用预览模式发布：

想带着她的真实数据试：正式站「设置 → 备份 / 恢复」复制，到预览站同一个地方粘贴恢复。

⚠️ 在开发分支上直接跑 `deploy.sh`（不带 preview）会被拒绝，这是故意的保险，
防止把做到一半的版本发给孩子。确认没问题后，我会合并回正式分支，再告诉你上线步骤。

## 六、数据与备份

**没有账号系统，也不需要。** 没有登录、没有服务器、没有任何网络请求
（除了第一次加载页面和按需取笔顺分片）。

所有数据只存在那台设备的浏览器里：

| 存的东西 | key |
|---|---|
| 每个字的最好成绩（星星） | `mzg.stars` |
| 要多练的字（字 + 错过几次 + 最近日期） | `mzg.wrong` |
| 练习页勾选的字 | `mzg.sel` |
| 设置（声音/语速/宽松度/起笔点/分组…） | `mzg.cfg` |

### ⚠️ 三种情况会丢

1. 清理 Safari 数据
2. 换设备
3. **换网址** —— 浏览器按网址隔离数据，`192.168.x.x:8080`、`hanzi-writing.pages.dev`、
   Claude 预览地址，在浏览器眼里是三台不同的设备

所以 app 里有 **设置 ⚙ → 备份 / 恢复**：

- **备份**：生成一段文字，「复制」粘到备忘录里存着
- **恢复**：把那段文字贴回去，星星、勾选、设置全回来

换网址搬家也走这条路。没备份过的话设置里会红字提醒「从未备份」。

启动时会向系统申请持久化存储降低被自动清理的概率，但那是「申请」不是保证，**该备份还是要备份**。

> iOS 的「添加到主屏幕」web app 有自己独立的存储空间，和 Safari 里打开的不共用。
> **固定从桌面图标进**，别一会儿桌面一会儿 Safari，否则星星看起来会「消失」。
