# 米字格练字本

给 5 岁小朋友的汉字**书写**练习（不是认字——认字在用洪恩识字）。
针对的具体问题：写在纸上时**位置、大小、间架结构**不稳。

线上地址（私有 Artifact，iPad Safari 打开后「添加到主屏幕」即可当 app 用）：
https://claude.ai/code/artifact/2243a2cf-b820-49d3-949d-a2460996ecdc

## 怎么用（实际流程）

```
洪恩／课本认字  →  【练习】跨单元挑字听写（测）  →  错的字自动进描红+默写（练）  →  打印字帖（纸上巩固）
```

三个页签：

- **学习** —— 按课本顺序浏览 41 课，点任意一个字进入「看笔顺 → 描红 → 默写」，每课可打印字帖
- **字库** —— 按主题浏览（数字、身体、家人、动物…），认字量大了之后横向串联用
- **练习** —— **勾选要听写／打印的字，可以跨单元一起选**。整组勾选点单元名前面的方块，
  也可以只点某几个字。底部一直显示已选字数，可以「开始听写」或「打印字帖」；
  「只选要求会写的」一键勾出本册 100 个写字表字

跨单元选是为了**带上前面学过的单元复习旧字**，不只测当前这一课。

## 学习页分组：两套，随时切

- **教材**（默认）—— 内置**人教版（2016 统编版）一年级上册识字表**，41 课 300 字，按课本顺序。
  每课下面标出这一课的字里哪些是本册**要求会写**的 100 字之一。数据在 `build/textbook.py`。
- **按笔画难度** —— 内置 9 关，从横竖起步到包围结构，按**写字**难度递进（和课本顺序无关）。

换册（比如一年级下册）时把字表加进 `build/textbook.py` 重新构建即可。

> 识字表（认识，300 字）和写字表（会写，100 字）是两回事，后者是前者的子集。
> ⚠️ 写字表按它自己的课次编排，和识字表的课次**对不上**（比如"月"在识字4 学认、在课文2 才学写）。
> 所以每课只能说"这一课的字里，**本册**要求会写的有几个"，不能说"这一课要求会写"。

## 它做什么

- **听写模式** —— 显示拼音，语音念「字 + 两个组词」（"地，大地的地，土地的地"——一个词孩子
  常常还对不上号），**出题顺序随机打乱**（打印字帖仍按课本顺序），自由书写不给任何提示；
  批改时并排显示"她写的 / 标准字"，并自动给出笔画数、位置偏向、大小的客观提示，由你判定对错
- **起笔点引导** —— 每一笔开始前，格子里标出红点（带笔序号）+ 方向箭头，并用语音说出米字格方位
  （"第一笔，从横中线的左边起笔"）。写字教学里起笔位置是一切的源头。
- **三步流程** —— 看笔顺动画 → 描红跟写 → 空格默写
- **四项打分** —— 位置 / 大小 / 间架 / 笔顺，每项单独给星，**语音念出最需要改的那一条**
- **反复练** —— 同一个字连写 N 遍，每遍的真实笔迹填进一行小格子，像真的练字本
- **打印字帖** —— A4 米字格描红页（1 格标准 + 2 格描红 + 3 格空白）

## 字库覆盖

**9574 个字**，等于 hanzi-writer-data 的全部内容。"魑魅魍魉"这种生僻字都有；
"龘""犇""燚"这类超生僻/异体字没有。任何字打进「今天练的字」都能直接练，
查不到的会在界面上明确列出来。

页面本身只带 392 个常用字（约 0.9 MB），其余按 unicode 码位分成 128 片，
用到哪个字才下哪一片（每片约 240 KB，一次不到 1 秒），下过就缓存住。

## 改字表

只有**闯关分组和主题分组**需要改字表——日常要练的字直接在 app 的「今天练的字」里输入即可，
不需要重新构建。

要改分组：编辑 `build/charset.py` 的 `LESSONS`（按笔画难度递进的闯关）和 `THEMES`（主题字库），然后：

```bash
/usr/local/bin/python3 build/make_chardata.py
```

如果 `build/cache/` 是空的（刚 clone），先跑一次（约 10 分钟，9574 个字）：

```bash
/usr/local/bin/python3 build/fetch_all.py
```

## 在 iPad 上用（脱离 Mac）

### 正式用：部署到自己的网址（免费，之后再也不用开电脑）

```bash
~/MyProjects/hanzi_writing/build/deploy.sh
```

第一次会让你登录 Cloudflare 并创建项目，然后给一个 `https://hanzi-writing.pages.dev`。
**这个网址任何设备、任何网络、任何时候打开都能用，不需要登录任何账号，不需要开 Mac。**
以后代码改了，再跑一遍同一条命令就更新。

在 iPad Safari 打开 → 分享 →「添加到主屏幕」→ 桌面上出现「练字本」图标，点开是全屏的。

### ⚠️ 换网址会丢记录，先备份

浏览器按**网址**隔离数据。`http://192.168.x.x:8080`（Mac 临时版）和
`https://xxx.pages.dev`（正式版）在浏览器眼里是两台不同的设备，记录不互通。

搬家三步：

1. 在**旧地址**打开 → 设置 ⚙ → 备份/恢复 → **复制** → 粘到备忘录
2. 打开**新地址** → 设置 ⚙ → 备份/恢复 → 把那段贴进「恢复」框 → 点**恢复**
3. 确认星星和勾选都回来了，再「添加到主屏幕」，以后只从桌面图标进

### 临时测试：从 Mac 直接连

改完代码想先在真机看一眼时用：

```bash
cd ~/MyProjects/hanzi_writing && /usr/local/bin/python3 build/serve.py
```

会打印一个 `http://192.168.x.x:8080`，iPad 和 Mac 连同一个 WiFi 即可打开。
关掉终端就失效——**这条路只用来测试，不要拿来长期给小朋友用**。

### 图标与全屏

`app/manifest.webmanifest` + `icon-{180,192,512}.png`（`build/make_icons.py` 生成）
让它加到主屏幕后有自己的图标、全屏运行、没有 Safari 地址栏。
`index.html` 头部的 `charset` / `viewport` 也是自己托管时必需的——
Artifact 外壳会自动加，自己部署就得有。

## 账号与数据

**这个 app 没有账号系统，也不需要。** 没有登录、没有服务器、没有任何网络请求
（除了第一次加载页面本身和按需取笔顺分片）。

所有数据都只存在那台设备的浏览器 localStorage 里：

| 存的东西 | key |
|---|---|
| 每个字的最好成绩（星星） | `mzg.stars` |
| 练习页勾选的字 | `mzg.sel` |
| 设置（语音/音效/宽松度/起笔点/分组/朗读声音/语速） | `mzg.cfg` |

也就是说：**换设备不同步，清掉 Safari 数据会丢，换了网址也会丢**
（`http://192.168.x.x:8080` 和 `https://xxx.pages.dev` 在浏览器眼里是两个不同的地盘，不共享数据）。

所以 app 里有 **设置 → 备份 / 恢复**：

- **备份**：生成一段文字，「复制」到备忘录里存着，或者「存成文件」放进 iCloud
- **恢复**：把那段文字贴回去，星星、字表、设置全回来

换网址迁移也走这条路：在旧地址备份 → 打开新地址 → 恢复。
没备份过的话设置里会红字提醒「从未备份」。

app 启动时还会调 `navigator.storage.persist()` 申请持久化存储，降低 iOS 自动清理的概率——
但这是"申请"，不是保证，**该备份还是要备份**。

> iOS 的「添加到主屏幕」web app 有自己独立的存储空间，和 Safari 里打开的不共用。
> 所以要固定从桌面图标进，别一会儿桌面一会儿 Safari。
